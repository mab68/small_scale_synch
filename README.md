# Simulating and Characterizing Non-Gaussian Small-Scale Polarized Emission

Python scripts are included in `src/`, with example notebooks in `examples/`, and notebooks used to generate some of the plots in the paper can be found in `paper_notebooks/`.

If you have any questions, feel free to reach out to Mark A. Bishop (mark.bishop@vuw.ac.nz) or Brandon S. Hensley (Brandon.S.Hensley@jpl.nasa.gov) via email.

## Requirements

The following dependencies are required:
```
numpy
healpy
scipy
pysm3
matplotlib
astropy
```

Some notebooks estimate the 2D Fourier power spectrum. In these cases, https://github.com/mab68/kea is used.
